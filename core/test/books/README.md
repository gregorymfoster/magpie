Small books in other formats, for the converter tests. All made by Calibre's
`ebook-convert` from one tiny public-domain-style EPUB (three short chapters,
a cover, a picture and a contents page): `pride.mobi` (old MOBI), `pride.azw3`
(KF8), `pride-combo.mobi` (MOBI and KF8 in one file, `--mobi-file-type both`)
and `pride.fb2`.
